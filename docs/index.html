netq

终端网络诊断 CLI

Node ≥ 20 MIT Win / macOS / Linux

同一套检查链支持菜单交互与子命令。面向人工排查与脚本/agent：失败时退出码为 1，机器输出用 --json。

  • 入口：netq 进菜单；或 netq doctor <host> 直接跑体检
  • 体检：DNS、Ping、TCP、HTTP、TLS 并行，输出 0–100 健康分
  • 配置：~/.netq/config.json（收藏与最近主机）
命令速查 README

Install

全局安装（推荐）

npm i -g @alexanderjcarter/netq

不安装，单次运行

npx @alexanderjcarter/netq doctor github.com

安装后执行 netq 或任意子命令；需已安装 Node.js 20+。

~/ netq doctor 
$ netq doctor github.com --ports 80,443
快速体检: github.com
✔ DNS: 20.205.243.166
✔ Ping: 连通
✔ TCP: 80,443 开放
✔ HTTPS: 200 (186ms)
✔ TLS: TLSv1.3 · 剩余 84 天
健康分: 100/100
· 各项检查通过，网络路径健康
$ netq tls github.com
✔ TLS: TLSv1.3 · 剩余 84 天
$

Commands

常用子命令

交互菜单调用的逻辑与子命令相同。脚本侧加 --json；安静模式部分命令支持 -q。

交互 / 手工

netq
netq doctor github.com --ports "80,443"
netq tls github.com
netq dns-compare github.com
netq watch 1.1.1.1 -c 5
netq tcp github.com 443

CI / Agent

netq doctor github.com --json
netq tls github.com --json
netq dns-compare github.com --json
netq listening --port 3000 -q
netq favorites list
netq help doctor

Subcommands

检查项一览

从出口 IP、解析差异到证书与端口，覆盖常见连通性排查路径。

doctor 并行 DNS / Ping / TCP / HTTP / TLS；健康分与建议；--export 写入报告目录
tls 握手结果：有效期、SAN、协议与密码套件
dns-compare 系统解析 vs Cloudflare / Google，标出记录不一致
watch 按间隔 Ping + TCP，终端刷新状态
dns / ping lookup 与扩展记录类型；系统 ping / traceroute
tcp / http 端口列表与范围；HTTP 状态码与重定向链
listening 本机监听套接字；Windows 可解析进程名
favorites 收藏目标的增删查跑

Machine output

JSON 契约

各子命令支持 --json，顶层字段固定，便于管道与 agent 解析。 

{
  "ok": true,
  "command": "doctor",
  "ts": "2026-07-30T00:00:00.000Z",
  "data": {
    "host": "github.com",
    "ports": [80, 443],
    "score": 100,
    "advice": ["各项检查通过，网络路径健康"],
    "checks": {}
  }
}

判定成败：进程退出码，或解析 ok 布尔字段。
