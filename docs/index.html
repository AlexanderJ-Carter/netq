netq

一眼看懂网络哪里出了问题

菜单交互 + 子命令脚本同一套能力。体检打分、TLS、DNS 对比、实时监视。

Install

一分钟上手

全局安装后直接运行 netq 进入交互菜单，或使用子命令写进脚本。

npm i -g @alexanderjcarter/netq

Commands

最常用的几条

交互与脚本共用同一套子命令；失败时退出码为 1。

日常排查

netq
netq doctor github.com --ports "80,443"
netq tls github.com
netq dns-compare github.com
netq watch 1.1.1.1 -c 5
netq tcp github.com 443

脚本 / Agent

netq doctor github.com --json
netq tls github.com --json
netq dns-compare github.com --json
netq listening --port 3000 -q
netq favorites list
netq help doctor

Capabilities

覆盖日常诊断

从出口 IP 到证书过期，一条工具链走完常见排查路径。

doctor
DNS + Ping + TCP + HTTP + TLS 并行体检，输出健康分与建议，可导出报告
tls
TLS 握手检查证书有效期、SAN、协议与密码套件
dns-compare
对比系统 DNS 与 Cloudflare / Google，快速发现污染或分流差异
watch
周期性 Ping + TCP 监视，终端刷新连通状态
dns / ping
lookup 与扩展记录类型；系统 ping / traceroute 路径定位
tcp / http
端口列表与范围检测；HTTP 状态码与重定向链
listening
本机 Listening 列表，Windows 可解析进程名
favorites
常用目标增删查跑，配置落在 ~/.netq/config.json

Machine output

统一 JSON 结构

所有命令支持 --json，方便 CI 与 agent 解析。

{
  "ok": true,
  "command": "doctor",
  "ts": "2026-07-30T00:00:00.000Z",
  "data": {
    "host": "github.com",
    "ports": [80, 443],
    "score": 100,
    "advice": ["各项检查通过，网络路径健康"],
    "checks": {}
  }
}

用退出码或 ok 字段判断成败即可。
