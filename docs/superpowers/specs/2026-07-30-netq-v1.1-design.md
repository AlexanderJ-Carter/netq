**日期:** 2026-07-30

## 目标

在现有 `lib` / `commands` / 交互共用架构上，完成一期「可感知的全面升级」：新诊断能力、交互体验、docs 视觉、配套测试。不做插件化、不做 ESM 重写。

- 新命令 `tls` / `dns-compare` / `watch` 可用，支持 `--json`，契约为 `{ ok, command, ts, data }`
- `doctor` 输出健康分与简短建议，可选纳入 TLS
- 交互菜单分组，默认主机读取 `recentHost`
- `docs/index.html` 视觉与内容更新到 v1.1
- `npm run lint` 与 `npm test` 通过

## 功能规格

### `netq tls <host> [--port 443]`

- 通过 TLS 握手获取证书：subject、issuer、validFrom/validTo、daysRemaining、SAN、协议、cipher
- `ok`: 握手成功且证书未过期
- 人类输出用 `kvTable`；JSON 走统一 `printJson`

### `netq dns-compare <host> [--type A]`

- 对比系统默认解析与公共解析器 `1.1.1.1`、`8.8.8.8`（可用 `dns.Resolver`）
- 输出各源地址集合与 `consistent` 布尔值
- `ok`: 至少系统解析成功；`consistent` 反映是否一致

### `netq watch <host> [--interval 2000] [--port 443]`

- 周期性：ping 一次 + 可选 TCP 探测；终端清屏刷新摘要
- Ctrl+C 退出；`--json` 不适用流式（仅首次打印说明或禁用），默认人类可读
- 支持 `-c` / `--count` 限制轮次（可选）；默认无限直到中断
- `--interval` 毫秒，下限 500，默认 2000

### `doctor` 增强

- 在现有 DNS/Ping/TCP/HTTP 后增加 TLS（443）检测
- 计算 `score`（0–100）与 `advice[]` 字符串建议
- 评分权重：DNS 25、Ping 15、TCP 25、HTTP 20、TLS 15
- 人类模式在结束时打印分数与建议；JSON 写入 `data.score` / `data.advice`

### 交互与配置

- `~/.netq/config.json` 增加 `recentHost`（字符串）
- 每次成功输入主机后更新；菜单输入默认值优先 `recentHost`
- 菜单分组：本机 / 连通诊断 / 进阶 / 收藏

### Docs

- 保留终端绿信号品牌
- Hero 演示包含 doctor 打分与新命令
- 功能列表增加 tls / dns-compare / watch
- 版本文案改为 v1.1
